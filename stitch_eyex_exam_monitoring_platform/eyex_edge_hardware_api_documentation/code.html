POST /api/violations Rate Limit: 60 req/min per Node

Ingest real-time edge computer-vision detections (bounding box coordinates, candidate tracker token, detection type, and confidence score) directly to the center chief supervisory console.

Authentication Headers Required on every telemetry packet
X-Edge-Node-ID: SECNODE-SW-BGS-02
Authorization: Bearer sec_live_948f21e0...c71
Content-Type: application/json
Payload Parameters JSON Body Schema
hall_id REQUIRED string (UUID / Hall Token)

Unique identifier or 8-character allocation code of the examination hall where the edge rig is deployed.

Example: "HALL-MOLYKO-02B"
tracker_id REQUIRED string

Temporary anonymized spatial tracking token assigned by the local DeepSort/YOLO edge tracking worker.

Example: "TRACKER #07"
activity_type REQUIRED enum • string

Classification of the detected examination anomaly. Must strictly match the approved GCE Board irregularity lexicon:

PHONE_DETECTED UNAUTHORISED_MATERIAL COMMUNICATION GAZE_DEVIATION
confidence REQUIRED float [0.0 - 1.0]

Inference model confidence probability threshold. Discard detections below 0.65 prior to dispatch.

Example: 0.942
snapshot_frame REQUIRED string (base64 image / URI)

Timestamped video frame crop with normalized bounding box coordinates overlay for immediate invigilator tablet review.

Example: "data:image/jpeg;base64,/9j/4AAQSkZJRg..."

Edge Device Integration Quick Tips

Field-tested architectural safeguards designed to maintain unbroken examination telemetry across remote regional centers with intermittent power and bandwidth constraints.

speed
Data Budgeting

Low Bandwidth Mode (<128 kbps)

Configure edge models to withhold continuous video streaming. Only dispatch compressed 480p bounding-box snapshot crops when inference exceeds confidence ≥ 0.70. Conserves uplink over 2G/3G regional relays.

--bandwidth-cap=128kbps --crop-only=true
vital_signs
Health Telemetry

Camera Heartbeat Ping (10s Intervals)

Transmit a lightweight 32-byte JSON ping every 10 seconds per RTSP camera sensor. Center Chief monitoring stations instantly alert invigilators if an optical feed is occluded, moved, or unplugged.

POST /api/heartbeat • KeepAlive 10s
save
Resilience Layer

Automatic Local SSD Cache

When WAN dropouts happen, the SecNode daemon switches automatically to a zero-loss local SQLite Write-Ahead Log. Once the connection re-establishes, the node fires /api/sync/offline-batch.

PRAGMA journal_mode=WAL • AES Encrypted
